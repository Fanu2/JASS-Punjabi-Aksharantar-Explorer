# 🪯 JASS Punjabi Aksharantar Explorer

### **Bridging Scripts • Exploring Language • Preserving Heritage**

A beautiful, practical desktop workspace for exploring **Punjabi Roman ↔ Gurmukhi transliteration data** using the [Aksharantar](https://github.com/AI4Bharat/IndicTrans2) corpus.

Built with **Python, PySide6, SQLite and Pandas**, the Explorer transforms a large transliteration dataset into an accessible environment for **search, exploration, learning, research and language technology experimentation**.

> **From Data to Deeper Understanding.**

---

## ✨ What is JASS Punjabi Aksharantar Explorer?

Language datasets are incredibly valuable — but raw datasets can be difficult to explore.

**JASS Punjabi Aksharantar Explorer** provides a focused desktop environment where you can interact with Punjabi transliteration data instead of simply viewing it as rows and columns.

Explore relationships such as:

```text
Roman Punjabi
      │
      ▼
Transliteration
      │
      ▼
Gurmukhi Punjabi
```

Search words and phrases, inspect transliteration pairs, study examples, examine dataset splits and discover patterns across a large Punjabi-language corpus.

# 🧠 Why Aksharantar?

Transliteration is an important bridge between scripts.

For Punjabi, users may encounter language written in:

**Gurmukhi**

```text
ਸਤ ਸ੍ਰੀ ਅਕਾਲ
```

and Romanized forms such as:

```text
sat sri akal
```

A transliteration corpus provides valuable data for studying how these representations correspond.

This makes Aksharantar useful for experimentation in:

* Natural Language Processing
* Indic-language computing
* Transliteration systems
* Language education
* Search
* Text normalization
* AI-assisted language tools

# 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/Fanu2/JASS-Punjabi-Aksharantar-Explorer.git
cd JASS-Punjabi-Aksharantar-Explorer
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Activate it on Linux/macOS:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Then launch the application using the project's main entry point.
